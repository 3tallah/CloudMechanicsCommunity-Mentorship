## Suggested 6-Week Self-Study Flow

Weeks 1-2:

- Azure fundamentals paths
- Portal navigation and core services

Weeks 3-4:

- Hands-on with compute, storage, networking
- Start AZ-104-aligned labs

Weeks 5-6:

- Monitoring, governance, and security basics
- Certification readiness review

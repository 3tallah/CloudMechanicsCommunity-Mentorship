# 📚 Learning Resources

This page is the community reference shelf for Azure learning.
It is intentionally curated so members can choose a learning path quickly instead of searching from scratch.

## How to use this page

Pick one primary course only.
Use Microsoft Learn as the official baseline.
Use labs and practice tests to validate understanding, not replace hands-on work.

Recommended order for most members:

1. AZ-900 fundamentals
2. AZ-104 administrator track
3. Hands-on labs
4. Practice tests and exam review

## Selection criteria

Resources below were prioritized using these signals:

- Instructor reputation and consistency in Azure content
- Course completeness and alignment to AZ-900 or AZ-104 skills
- Community visibility from well-known YouTube playlists and current Udemy search results
- Udemy rating and review volume where available
- Practical value for Arabic-speaking learners who may switch between Arabic and English sources

Udemy ratings and review counts below were checked from public search results in April 2026 and can change over time.

## Best starting paths

### Arabic-first path

If you prefer to learn in Arabic, start here:

1. Microsoft Learn fundamentals paths
2. AZ-900 Arabic course
3. AZ-104 Arabic course
4. AZ-104 labs

Best fit:

- Learners new to Azure
- Learners preparing for AZ-900 then AZ-104
- Members who prefer explanations in Arabic but can still use English Microsoft documentation when needed

### English-first path

If you are comfortable with English technical content, start here:

1. Microsoft Learn fundamentals and AZ-104 paths
2. One full English YouTube or Udemy course
3. AZ-104 labs
4. Practice tests

Best fit:

- Learners targeting certification faster
- Learners already working in English-speaking technical environments
- Members who want the widest choice of updated content

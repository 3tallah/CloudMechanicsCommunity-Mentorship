## Lab 1: Azure Portal Basics

Title: Azure Foundations in Portal

Objective:
Build and validate your first basic Azure environment.

Steps:

1. Create a Resource Group
2. Deploy a Virtual Machine
3. Review networking objects created with the VM
4. Validate access and basic configuration
5. Clean up all resources

Expected Outcome:

- You understand resource grouping and lifecycle
- You can deploy and inspect a VM confidently
- You can map relationships between VM, VNet, Subnet, and NSG

---

## Lab 2: Networking Foundation

Title: Build a Secure Base Network

Objective:
Design and implement foundational Azure networking with access control.

Steps:

1. Create a VNet and multiple subnets
2. Create and configure an NSG
3. Apply NSG rules to the correct subnet/workload
4. Validate traffic behavior
5. Refine rules and test again

Expected Outcome:

- You can design address spaces and subnet boundaries
- You understand NSG rule evaluation and effect
- You can enforce secure default patterns

# Cloud Mechanics Community Mentorship - Community Content Kit

> **A practical, community-led learning space for Azure, Microsoft 365, certifications, and hands-on labs.**

This repository contains the public-ready content used in the Cloud Mechanics Community mentorship program.
The model is simple: guided learning tracks, practical labs, and community support through Telegram.

## 🌱 Getting started

If you are new to the community, start with these steps:

1. Read [Start Here](content/01-start-here.md).
2. Follow [Development Resources and Lab Building Guide](content/12-development-resources-lab-building-guide.md).
3. Review the [Reference Guide (Latest)](#reference-guide-latest) to pick your next topic.
4. Join the Telegram topics and use Discussions for continuous support between live sessions.

If you're a community leader or contributor and want to support the Cloud Mechanics Community mentorship journey, this repository includes everything needed to guide onboarding, learning paths, labs, and topic-based collaboration.

**To make it easier to come back later, you can also [star (🌟) this repository](https://github.com/3tallah/CloudMechanicsCommunity-Mentorship) and review [how starring works on GitHub](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars).**

---

## Program Model

- Live session cadence: every 2 weeks
- Session commitment: based on mentor and community availability
- Support model: ongoing Telegram chat support between sessions
- Learning model: practical labs, discussion, and guided learning paths

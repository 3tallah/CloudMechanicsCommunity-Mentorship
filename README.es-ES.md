# Cloud Mechanics Community Mentorship - Kit de Contenido Comunitario

> **Un espacio de aprendizaje práctico liderado por la comunidad para Azure, Microsoft 365, certificaciones y laboratorios prácticos.**

Este repositorio contiene el contenido listo para el público utilizado en el programa de mentoría de Cloud Mechanics Community.
El modelo es sencillo: rutas de aprendizaje guiadas, laboratorios prácticos y soporte comunitario a través de Telegram.

## 🌱 Primeros pasos

Si eres nuevo en la comunidad, comienza con estos pasos:

1. Lee [Start Here](content/01-start-here.md).
2. Sigue la [Development Resources and Lab Building Guide](content/12-development-resources-lab-building-guide.md).
3. Revisa la [Reference Guide (Latest)](#reference-guide-latest) para elegir tu próximo tema.
4. Únete a los temas de Telegram y utiliza Discussions para soporte continuo entre las sesiones en vivo.

Si eres un líder comunitario o colaborador y deseas apoyar el viaje de mentoría de Cloud Mechanics Community, este repositorio incluye todo lo necesario para guiar la incorporación, las rutas de aprendizaje, los laboratorios y la colaboración basada en temas.

**Para facilitar el regreso más tarde, también puedes [dar una estrella (🌟) a este repositorio](https://github.com/3tallah/CloudMechanicsCommunity-Mentorship) y revisar [cómo funcionan las estrellas en GitHub](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars).**

---

## Modelo del Programa

- Cadencia de sesiones en vivo: cada 2 semanas
- Compromiso de sesión: basado en la disponibilidad del mentor y la comunidad
- Modelo de soporte: soporte continuo vía chat de Telegram entre sesiones
- Modelo de aprendizaje: laboratorios prácticos, discusión y rutas de aprendizaje guiadas
